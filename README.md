A program that writes one joke pickup line, under 200 characters, aimed at a robot or an AI:

> You must be my training data, because I can't stop overfitting to you.

The line is 70 characters: the joke turns on overfitting — the machine premise itself — instead of the worn battery, charging, or reboot moves.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `out/entry.txt` — exactly the line above, no trailing newline, deterministic across runs.
